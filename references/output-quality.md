# 章节、SVG 与交付质量

## 章节证据

每章维护一个可机读记录。推荐字段，但不限定页面布局：

```json
{
  "title": "本章问题或主题",
  "part": 1,
  "start": 0.0,
  "end": 120.0,
  "points": [{"text": "要点", "time": 30.0, "kind": "speaker_claim"}],
  "quotes": [{"text": "短引", "start": 35.0, "end": 40.0, "editing": "省略口头填充"}],
  "visual_anchors": [{"time": 45.0, "file": "assets/frame.jpg", "observed": "实际看到的内容"}],
  "diagram": {"type": "decision-tree", "claim": "本图要解释的关系", "source_times": [30.0, 45.0], "svg_file": "assets/diagram.svg"}
}
```

秒数是对应分 P 的时间；跨 P 章节拆成多个 source range，不能用一串累计时间直接拼视频回跳。每章及全篇覆盖范围都要可追溯。开场和结尾可放导读/收束，不要强制拆出没有意义的章节。

引用：保留原话立场和限定语。删口头填充、校正专名需说明；大幅改写改标“转述”。字幕与画面冲突时分别记录看到/听到什么，不能静默合并成不存在的结论。对不确定数字尤其谨慎。

讲者用“最佳”“全覆盖”“不可能出错”等表述时，保留为其观点或案例观察，不转写成页面的无条件保证。不默认替作者研究所有工具当前性能。

## SVG 先确定论点，再选形式

| 内容 | 图形 | 必须表达 | 常见错误 |
|---|---|---|---|
| 流程或操作 | 步骤、泳道、路径 | 输入、动作、交接、输出 | 画出视频没讲的先后依赖 |
| 概念 | 分层、关系网 | 概念边界与关系词 | 把并列类别用箭头画成因果 |
| 随时间改变 | 时间线 | 真实节点、先后或周期 | 虚构日期或伪造精确间隔 |
| 对比与选择 | 矩阵 | 同一维度的差异 | 没有依据的星级、分数、排名 |
| 风险和误区 | 检查表、决策树 | 判断条件、失败结果、处理路径 | 只换卡片文字，没有决策关系 |
| 数据 | 简图 | 可核实数值、单位、来源与限制 | 从模糊截图编造数值 |
| 因果 | 因果链 | 原因、机制、结果及限定 | 将相关性、工具清单画成因果 |

图中没有数据就不画带数值坐标的趋势图。关系网络为示意时注明“功能示意”，不要让虚构节点看起来像真实论文关系。章节确实相似可复用视觉组件，但每张图必须有自己的内容和关系，不为凑差异选择不合适的图形。

## SVG 技术检查

- 设置 viewBox、role=img 和清楚的 title/aria-label；字号在目标宽度可读。
- marker、clipPath 等 ID 按图唯一。全局 CSS `marker-end:url(#arrow)` 会覆盖逐图 ID，必要时为边使用对应图的内联 style 或作用域规则。
- 保留箭头与标签的空间；长英文专名换行或缩短配图文释义，不缩到不可读。
- SVG XML 可解析不代表版式正确，实际看图确认箭头、遮挡、裁切与真实语义。

## 页面可用性

默认本地 HTML，内容按视频自然结构安排。目录时间、关键点回跳、短引、视觉锚点、完整转写与素材来源能被找到。转写时间按钮用于本地音频定位，另有独立原视频回跳。

长视频的原稿折叠或可搜索，避免抢占正文。章节搜索与目录能协同：点击目录时清除造成目标隐藏的筛选。关键画面可按需展开，不要把一张巨大的接触表当作全部视觉证据。

离线打开不使用 fetch 本地 JSON、外部字体或 CDN；必要数据内嵌，或用浏览器直接支持的本地资源路径。窄屏只允许图表容器按需横向滚动，不让整页溢出。优先检查真实内容密集和 SVG 最复杂的章节。

## 交付白名单

项目根目录可含 source、transcripts、tools 与凭证，但 `dist` 只含可交付内容。先生成显式 JSON 清单再复制，如：

```json
{"files": ["index.html", "assets/diagram.svg", "assets/frame.jpg", "source/public-metadata.json", "source/audio.mp3", "source/verification.json", "transcripts/transcript.txt"]}
```

运行 `scripts/package_site.py --help` 了解参数。清单列的是相对路径，不用通配符；以当前项目实际资源为准。脚本拒绝目录越界、常见凭证、Netscape Cookie 内容和敏感 JSON 键，并检查 HTML 本地资源与 fragment ID；这些检查不能替代审查任意格式中的秘密。随机命名 Cookie 同样禁止进入清单。

公开元数据只保留标题、作者、ID、分 P、简介、标签、时长、公开视频地址等必要字段。不要发布临时签名媒体 URL、Cookie、认证请求头或包含用户账户状态的完整网页。

最终报告区分：时长通过、完整解码通过、转写完成、字幕交叉核对、画面实际检查、浏览器交互测试。没有运行的检查写“未验证”；不要统称“全部验证通过”。
