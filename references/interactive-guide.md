# 快速引导与关键节点

## 第一次的简短引导

给用户这三个动作，信息已齐时不再要求重填：

1. 提供视频链接，或本地视频/音频路径。
2. 确认完整/片段/分 P 与 D 盘目录；HTML 为默认成果。
3. 若需要登录，选择浏览器登录态或已导出的 Cookie 文件；无需发送 Cookie 内容。

然后盘点当前上下文，将缺失项尽量合成一轮、最多三个短问题。不要把默认可决定的配色、字体、章节数或 SVG 类型拿来占用问答。

## 苏格拉底式澄清，采用快速节奏

问题用于澄清目标和真正的矛盾，不是展示流程。例如：

- 用途不清：“你主要想学懂原理，还是照着操作？这会决定我保留哪些细节。”
- 链接有 t 参数：“按完整视频整理，还是只看定位点之后？”已有“完整”指令时不再问。
- 对应多 P：“检测到 4 个分 P。你说的完整是当前 P 还是全部 4 P？”不要自动扩成 UP 主全部视频或整个合集。
- 输出目标矛盾：“要保留逐字稿可回听，还是只交精简笔记？”默认含可折叠/可搜索原稿，别强迫二选一。

先提出最关键的问题，收到回答后复述一行具体方案并执行；仅当回答产生新矛盾时再追问，不设固定轮数。用户已在同一消息明确所有条件，可直接说明方案并执行；不要制造批准口令。

## 执行中的提问边界

| 节点 | 怎么做 |
|---|---|
| 获取公开元数据、检查本地工具 | 直接做，与等待回答并行推进 |
| 安装必要且缺失的项目依赖 | 遵循当前运行环境权限；安装与缓存留 D 盘，复用现有依赖 |
| 使用登录态 | 确认浏览器/文件及指定来源授权；用户已授权则不重复询问 |
| 数据库被浏览器占用 | 说明具体错误，请用户保存工作并完全退出对应浏览器；不要自行结束用户进程 |
| DPAPI 解密失败 | 停止无效浏览器重试，指导导出当前站点 Cookie；能继续的公开材料照常处理 |
| 用户导出为随机文件名 | 只检查格式与是否含目标域登录 Cookie，不显示值；需要时让用户确认这是其导出文件，不自行推定认证授权 |
| 时长异常重试两次仍失败 | 展示对应 P 的期望/实测/差异，问是修复来源还是接受明确标注的局部材料 |
| 听不清、画面与口述矛盾 | 优先交叉核对；仍不清楚就标注。只有影响核心结论时才中断问用户 |
| 发现额外付费服务、外部音频上传或范围扩大 | 先明确新增行为；不把视频分析授权当成该行为的授权 |
| 章节大纲 | 正常任务给简短进度，不强制停下来批准；仅当内容范围或用户决策发生变化时问 |

技能本身不要求额外的下载批准、发布批准或逐章验收。原生权限和实际外部行为仍按当前环境处理。自动审批拒绝时，说明被拒动作和理由，不换路径绕开。

## Cookie 导出引导

先确认浏览器与平台，再提供简短逐步指导；需要推荐扩展时当场核实当前官方说明和商店链接，不把历史扩展状态当作永久事实。

指导的目标是：登录目标站点 → 仅导出当前站点 → Netscape 格式 → 保存为 D 盘项目中的 Cookie 文件 → 回复路径/“已保存”。不让用户复制会话凭证到聊天，也不要求导出所有网站。

导出后只检查文件存在、首行格式、目标域条目及必要 Cookie 名称是否存在；不要打印 Cookie 行或值。能取得登录后字幕或明确认证字段才标记登录验证成功，“文件能解析”不足以证明登录有效。

## 进度和最后交付

进度说明新发现、已验证事实与下一步；长时间下载或转写期间不要让用户误以为卡住。不要承诺普通聊天结束后继续后台工作。

结束给 HTML 与离线包链接、一句内容概括、时长和转写校验摘要、真实存在的限制。不要附上凭证路径截图或大段工具日志。
