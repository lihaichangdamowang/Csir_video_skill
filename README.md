# Csir_video_skill

将 B 站等视频或本地视频整理为可回查的中文 HTML 精读笔记。

显示名为 **Csir_video_skill**，内部调用名为 **csir-video-skill**。这是一份供 Codex 使用的技能，包含工作流说明、交互引导和辅助脚本；不是独立的一键下载软件。

## 使用

将技能文件放入本地可发现的 `skills/csir-video-skill/` 目录，调用时提供视频链接或本地视频路径：

```text
$csir-video-skill 分析这个视频：视频链接。
完整分析，生成 HTML，文件放 D:\Writing\视频\新项目。
```

也可以直接说：

```text
用 Csir_video_skill 分析这个视频，先快速问我缺什么，确认后继续。
```

默认采用**快速引导**：只询问缺失信息，确认后连续执行，在范围变化、登录受阻或关键证据不足时再提问。首次使用会简要说明链接、范围、目录和登录凭证的提供方式。

## 方法

1. 明确用途、视频范围、输出目录和认证方式。
2. 用 yt-dlp 保留标题、UP 主、分 P、简介、标签、封面、时长等元数据。
3. 下载当前可用的最佳音轨，保留原音频并转 MP3。
4. 使用 ffprobe 校验时长；差异大于 5% 时有界重试或标记异常，并检查解码错误。
5. 默认本地 Whisper large-v3-turbo + 中文 zh 转写；平台字幕用于交叉核对。
6. 结合完整转写和实际画面自然拆章，保留问题、误区、步骤与结论中真正存在的内容。
7. 按章节关系生成 SVG：流程、分层、矩阵、时间线、决策树、简图或因果链。
8. 生成带时间回跳、短引、视觉锚点、转写搜索和本地音频定位的 HTML，验证后白名单打包。

不固定章节数，不套用重复图壳，不把讲者观点写成已验证事实。

## 运行条件

按任务使用 Python、yt-dlp、FFmpeg/ffprobe；本地转写另需 faster-whisper、numpy 和兼容的 turbo 模型。优先复用已有环境，不自动配置外部模型密钥。运行脚本前可查看 `--help`。模型需提前下载，转写脚本不会隐式联网下载模型。

脚本已验证真实音频的时长与解码检查、短片段转写及原时间偏移保留；打包脚本还验证了常见凭证内容拒绝、目录越界和资源缺失处理。脚本检查不等于全面安全审计或浏览器视觉验证。

## 凭证与成果

Cookie 仅在用户授权后于本机用于指定视频来源，不要求粘贴到聊天，不进入 HTML、日志或交付包。交付目录按显式白名单生成；不上传视频、Cookie、模型、依赖和工作缓存。

默认中文、完整视频、本地 HTML、D 盘保存，用户明确指定的设置优先。外部发布、额外付费服务与音频外传不属于默认行为。
